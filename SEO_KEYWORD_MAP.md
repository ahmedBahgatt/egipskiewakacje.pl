# SEO Keyword Ownership Map — hub pages

Source of quantitative demand: SEMrush Keyword Gap export
`gap.keywords_2025-12-23T19_51_00.108Z.csv` (2,581 keywords; competitors:
sekretyegiptu.pl, dziendobryegipt.pl, czwartapiramida.pl, hurghada.pl,
wycieczkipopolsku.pl). Volumes/KD below are read from that file — not invented.

> This is a competitor **gap** export, not the full keyword universe. Absence of a
> phrase here does NOT mean zero demand. Legitimate conversion pages with no gap
> keyword (e.g. Wycieczki prywatne) are kept and marked accordingly.

## Ownership model (anti-cannibalisation)

- **Destination hubs** own `destination + wycieczki/fakultatywne` intent.
- **Category hubs** own broad `activity/type` intent.
- **Individual tour pages** own specific `product/entity` intent (Orange Bay, Abu
  Dabbab, Sataya, Hamata, Paradise, Grand Aquarium, Parasailing, Seascope, …).

Category/destination hubs **mention and link** the specific entities but must not
target their exact primary query as the page's own primary keyword.

Real inventory (drives Quick Facts, honest counts): 78 tours — Hurghada 39,
Marsa Alam 20, Sharm el Sheikh 19. By category: Kair 10, Luksor 4, Rejsy 15,
Snorkeling 7, Nurkowanie 5, Safari 16, Atrakcje 13, Prywatne 4.
